# BotBuilf

Aplikasi **FELIXIORITY** — visualisasi user dan server panel Pterodactyl dalam ruangan pixel interaktif —
berada di folder [`FELIXIORITY/`](FELIXIORITY/README.md). Lihat README di sana untuk menjalankan lokal dan deploy ke Vercel
(atur **Root Directory** = `FELIXIORITY`).

Aplikasi Android **FxB RestApi** (Flutter native, backend `https://api.felixiority.xyz`) berada di folder
[`fxb_restapi_app/`](fxb_restapi_app/README.md). APK dibangun oleh workflow `.github/workflows/fxb-android.yml`.
