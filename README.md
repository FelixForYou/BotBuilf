# BotBuilf

Repositori ini berisi dua aplikasi Next.js milik **FELIXIORITY**:

| Folder | Isi |
| --- | --- |
| [`FxB-RestApi/`](FxB-RestApi/README.md) | **FxB RestApi** — layanan REST API publik (downloader, AI, AI image, entertainment, tools) dengan API key free/premium, pembayaran, dashboard user & admin, dan dokumentasi interaktif. Deploy ke Vercel dengan **Root Directory = `FxB-RestApi`**. |
| [`FELIXIORITY/`](FELIXIORITY/README.md) | Visualisasi user dan server panel Pterodactyl dalam ruangan pixel interaktif. Deploy ke Vercel dengan **Root Directory = `FELIXIORITY`**. |
