# Lisensi aset pixel

Semua berkas di folder ini (`characters/`, `furniture/`, `tiles/`) dihasilkan oleh
`scripts/generate-assets.mjs` dan merupakan karya asli proyek FELIXIORITY. Tidak ada aset pihak ketiga.

Aset dirilis sebagai **CC0 1.0 (domain publik)**: boleh dipakai, diubah, dan didistribusikan ulang
untuk keperluan apa pun tanpa atribusi.
